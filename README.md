# Enterprise RAG Agent

## Overview

An enterprise knowledge assistant that uses:

- Streamlit
- LangChain
- ChromaDB
- OpenAI
- Retrieval-Augmented Generation (RAG)
- Agentic AI

## Features

- Upload PDF, TXT, CSV, Excel
- Semantic Search
- AI Agents
- Context-aware responses

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py
